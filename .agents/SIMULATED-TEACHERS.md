# Docentes simulados — hipótesis, no investigación humana

Todas las personas, respuestas y comparaciones de este perfil son **SIMULADAS**. No hay usuarios reales todavía. Usar [CONTRACTS.md](CONTRACTS.md); no contactar docentes ni colegios.

## Perfiles ficticios de revisión

- **D1, tutora de 1.º–2.º:** baja confianza digital, preparar lectura sencilla con poco tiempo.
- **D2, docente de 3.º–4.º:** localizar material por curso/materia y adaptar una actividad manteniendo el original.
- **D3, docente de 5.º–6.º:** revisar formato Markdown/vista previa y distinguir borrador de propuesta.
- **D4, coordinación pedagógica:** revisar y rechazar con explicación, sin atribuirse aprobación editorial real.
- **D5, docente que usa teclado y zoom:** recorrer las mismas tareas; no simula de forma representativa toda discapacidad ni sustituye auditoría de accesibilidad.

Son lentes heurísticas, no muestras de población. No inventar nombres de centros, testimonios o comportamientos observados.

## Procedimiento de escenarios

1. Fijar versión, tarea, precondiciones y datos ficticios: invitación → encontrar libro → previsualizar adaptación → enviar propuesta; coordinación revisa. Si falta una pantalla, analizar maqueta/código y señalarlo.
2. Para cada perfil anotar expectativa, posible confusión, gravedad y recomendación. Citar fuente archivo:línea o evidencia local disponible. Separar heurística de observación de una ejecución técnica real.
3. Proponer pruebas futuras para las hipótesis; no declarar «los docentes prefieren».

## A/B SIMULADO reproducible

1. Definir hipótesis y una sola diferencia A/B (por ejemplo, etiqueta de propuesta), manteniendo tarea y estado iguales. Registrar variantes exactas y fuentes.
2. Aplicar cada perfil a ambas variantes; alternar orden A→B/B→A para detectar sesgo del propio ejercicio, **no como aleatorización humana válida**.
3. Usar rúbrica ordinal explícita: 0 = siguiente paso ambiguo; 1 = reconocible con ayuda; 2 = claro según heurística. Separar claridad, reversibilidad y distinción borrador/propuesta. Cada puntuación exige motivo y se etiqueta SIMULADA.
4. Tabla `perfil ficticio | tarea | A | B | fundamento | incertidumbre`. No inventar tiempos, conversiones, significación estadística o porcentajes de satisfacción. Un recorrido automatizado puede medir pasos técnicos, no preferencia docente.
5. Concluir como hipótesis («B podría aclarar el envío; comprobarlo con docentes en futuro estudio autorizado»), o sin diferencia concluyente. No elegir variante que incumpla gates aunque puntúe mejor.
